# PromptForge

PromptForge compiles, refactors and checks reusable prompt packages. Its captured workflow includes the developer instructions, user template, output contract, guardrails and evaluations.

## Native plugin

The [plugin package](adapters/chatgpt-plugin/) contains the released skill, icon and host manifests. The [source record](origin/source.json) identifies the captured editor and private release, preserves every original conversation starter, and records hashes for the packaged files.
