# FloorPlan-R

Conceptual home floorplans from plain specs or photos: adjacency (Mermaid), scaled SVG mockups, editable layouts, DXF/SVG export. Accept style cues from reference images. Rapid iteration for couples/teams. Hands off to @HomeVisual-R for 3D/exterior renderings, @HomeEstimate-R for cost/budget.

## Native plugin

The [original plugin release](adapters/chatgpt-plugin.tgz) contains the exact archived package. The [readable package](adapters/chatgpt-plugin/) preserves the instruction body and icon, and maps each original upload name to its installed reference path. The [source record](origin/source.json) records the original editor settings, all 12 conversation starters and the SHA-256 of each of the 11 knowledge uploads.
