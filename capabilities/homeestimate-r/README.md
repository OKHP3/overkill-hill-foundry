# HomeEstimate-R

Generates detailed material takeoffs and cost estimates for single-family homes. Provides itemized lists (lumber, concrete, roofing, siding, drywall, fixtures, etc.), cost breakdowns, and ranges. Iterates quickly and hands off floorplans or visuals to siblings.

## Native plugin

The [original plugin release](adapters/chatgpt-plugin.tgz) contains the exact archived package. The [readable package](adapters/chatgpt-plugin/) preserves the instruction body and icon, and maps each original upload name to its installed reference path. The [source record](origin/source.json) records the original editor settings, all 12 conversation starters and the SHA-256 of each of the 14 knowledge uploads.
