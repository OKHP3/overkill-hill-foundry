# foundry-hmt01-homestead-r

FoundRy HMT01 Homestead-R is currently an early-stage HomeTools prompt and
visual-identity asset repository. It is not a runnable property-management
application or GPT implementation in this checkout.

## Start here

- [HomeTools prompt and image assets](assets/hometools/)
- [Technology inventory](docs/TECHNOLOGY-INVENTORY.md)
- [Repository guidance](AGENTS.md)
- [Local Agent Skills catalog](.agents/skills/README.md)

## Current contents

- Two related prompts and two 1024 x 1024 PNG visual assets describing the
  HomeTools icon identity. They are grouped under `assets/hometools/`.
- A repository-local Agent Skills library used for project and skill
  maintenance. These skills are tooling, not evidence of an HMT01 runtime.

## Current status and boundaries

The repository metadata names homestead and property management as the
declared product direction. The checkout does not yet define the mission,
users, workflows, data model, integrations, runtime, or deployment model.
Those areas remain unresolved rather than implemented.

Do not infer a working property-management product from the repository name,
prompts, images, or local Agent Skills. Preserve the prompt and visual assets
until an explicit product specification establishes a different boundary.
